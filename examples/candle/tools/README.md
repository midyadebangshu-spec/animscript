# The Candle: how the example is made

`../candle.anim` is generated by these scripts (Python 3 with numpy), the way an animator would build a puppet from
painted parts: the drawing is data (brush strokes), the performance is a keyed timeline, and the flame is equations.

```bash
python3 tools/build.py candle.anim          # from examples/candle/
anim frames candle.anim -o /tmp/candle      # then: ffmpeg -framerate 24 -i /tmp/candle/f%04d.png -pix_fmt yuv420p candle.mp4
```

| file | what it does |
|---|---|
| `trace/trace_reference.py` | traces the ink lines of a reference drawing (a right-profile head) into long centre-line strokes with their thickness (`trace/paths.json`, `trace/ink.npy`; run it with the path of the image to redo the tracing) |
| `paint.py` | a small "hand": loose pressure-varying ink lines, ragged marker-hatched fills, shading scribbles; emits `layer.stroke(brush, points)` statements |
| `trace_head.py` | turns the traced lines into brush strokes (pressure from the drawn thickness) and snaps the paint fills to them |
| `painting.py` | the base painting: wall, window, shelf, table, candle, torso, scarf, head, hair, ear, eye, mouth |
| `parts.py` | the extra drawings: five eyes, three brows, four mouths, the arm with a match, the dusk wash, the glow and the face light |
| `rig.py` | the puppet: poses per frame (torso entrance with a bounce, head with springs, hair and scarf follow-through, a two-bone arm with inverse kinematics), the expression schedule, key compression |
| `build.py` | writes the scene: layers with pivots, the flame / smoke / cover shapes, the keyed `timeline:` and the `main:` sequence |

What the language does here: every body part is a `paint_layer` (brush strokes, libmypaint) with its own pivot; the
timeline keys `position`, `rotation` and `opacity` of the layers and of the camera; the flames and the smoke are
`curve(...)` shapes whose vertices are moved every frame by `drive` equations (sine sway, seeded `noise`, an ignition
envelope with `smoothstep`), and the glow and the face light flicker with a sum-of-sines equation on `opacity`.
The renderer caches each painted layer, so only the moving parts cost anything per frame.
